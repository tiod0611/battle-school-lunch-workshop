# 오늘의 왕 — 급식 건강 점수 채점 알고리즘

> **동기화 원칙**: 이 문서는 채점 로직 코드(`backend/app/services/scoring.py` 예정 경로)와 항상 동기화되어야 한다. 배점, 키워드 목록, 계산식 중 하나라도 코드에서 변경되면 이 문서도 같은 커밋 또는 같은 PR 내에서 함께 갱신한다. 반대로 이 문서의 기준이 바뀌면 코드도 반드시 함께 수정한다.

## 1. 개요

"오늘의 왕" 토너먼트에서 두 학교의 중식 메뉴를 비교할 때 사용하는 **건강 점수(Health Score)**의 산출 기준을 정의한다. 점수는 0~100점 범위이며, 각 대결에서 더 높은 점수를 받은 학교가 승리한다. 동점일 경우 [5절 타이브레이커](#5-동점-처리-타이브레이커) 규칙을 적용한다.

입력 데이터는 NEIS 급식식단정보 API(`data/openapi.json`의 `MealServiceDietInfoRow`)의 `DDISH_NM`(요리명), `NTR_INFO`(영양정보), `MLSV_YMD`(급식일자) 필드를 사용한다.

## 2. 총점 구성

| 항목 | 배점 범위 | 설명 |
|------|-----------|------|
| 기본 점수 | 20점 (고정) | 모든 학교에 동일하게 부여되는 기준 점수 |
| ① 제철 재료 반영도 | 0 ~ 25점 | 메뉴명에 포함된 제철 재료 키워드 개수 기준 가점 |
| ② 탄단지 비율 적정성 | 0 ~ 30점 | 탄수화물·단백질·지방의 에너지 비율이 권장 범위에 근접할수록 가점 |
| ③ 반찬 수(메뉴 다양성) | 0 ~ 25점 | 요리명 항목 개수 기준 가점 |
| ④ 인스턴트/가공식품 감점 | 0 ~ -20점 | 가공식품 키워드 포함 시 감점 |

```
총점 = 20 + ① + ② + ③ − ④   (0 ~ 100 범위로 clamp)
```

---

## 3. 항목별 계산식

### ① 제철 재료 반영도 (0~25점)

`MLSV_YMD`의 월(月)로 계절을 판별하고, 해당 계절의 제철 재료 키워드가 `DDISH_NM`에 몇 개 포함되는지로 점수를 매긴다.

**계절 판별**: 봄(3~5월), 여름(6~8월), 가을(9~11월), 겨울(12~2월)

**제철 재료 키워드 목록 (v1, 최초 배포용 — 추후 확장 예정)**

| 계절 | 키워드 |
|------|--------|
| 봄 | 딸기, 냉이, 두릅, 봄동, 취나물, 죽순, 완두콩, 마늘종, 도다리 |
| 여름 | 수박, 참외, 옥수수, 애호박, 감자, 오이, 가지, 열무, 복숭아 |
| 가을 | 사과, 배, 감, 밤, 고구마, 버섯, 전어, 갈치, 단호박 |
| 겨울 | 귤, 굴, 시금치, 배추, 무, 호박, 방어, 대구, 냉이 |

**배점**:

| 매칭 키워드 개수 | 점수 |
|------------------|------|
| 0개 | 0점 |
| 1개 | 10점 |
| 2개 | 18점 |
| 3개 이상 | 25점 |

### ② 탄단지 비율 적정성 (0~30점)

`NTR_INFO`에서 탄수화물(g), 단백질(g), 지방(g) 값을 파싱하여 에너지 비율을 계산한다.

```
탄수화물 kcal = 탄수화물(g) × 4
단백질 kcal   = 단백질(g) × 4
지방 kcal     = 지방(g) × 9
총 kcal       = 위 세 값의 합
각 비율(%)    = 항목 kcal ÷ 총 kcal × 100
```

**권장 범위** (2020 한국인 영양소 섭취기준 에너지적정비율 기준):

| 영양소 | 권장 비율 |
|--------|-----------|
| 탄수화물 | 55% ~ 65% |
| 단백질 | 7% ~ 20% |
| 지방 | 15% ~ 30% |

**배점**: 3개 항목 각각 최대 10점(합산 30점).

- 권장 범위 내: 10점
- 범위를 벗어난 경우: `max(0, 10 − 벗어난 퍼센트포인트 × 2)` (예: 범위보다 3%p 초과/미달 시 10 − 6 = 4점)

### ③ 반찬 수(메뉴 다양성) (0~25점)

`DDISH_NM`은 항목이 `<br/>`로 구분되어 나열된다. 항목 개수(밥, 국 포함 전체 메뉴 수)를 센다.

| 메뉴 개수 | 점수 |
|-----------|------|
| 1~3개 | 5점 |
| 4~5개 | 15점 |
| 6~7개 | 20점 |
| 8개 이상 | 25점 |

### ④ 인스턴트/가공식품 감점 (0~-20점)

**가공식품 키워드 목록 (v1)**: 소시지, 햄, 베이컨, 스팸, 맛살, 어묵, 통조림, 냉동, 즉석, 라면, 핫도그, 너겟

메뉴명에 위 키워드가 매칭될 때마다 **-5점**씩 감점하며, 최대 **-20점**(4개 매칭)까지만 반영한다.

---

## 4. 파싱 실패 시 처리

`NTR_INFO` 또는 `DDISH_NM`을 파싱할 수 없는 경우(형식 변경, 결측 등) 해당 항목은 0점으로 처리하고, 전체 채점은 계속 진행한다(개별 항목 파싱 실패가 전체 대결을 무효화하지 않는다).

## 5. 동점 처리 (타이브레이커)

총점이 동일한 두 학교는 아래 순서로 우선순위를 정한다.

1. 반찬 수(③ 항목의 원본 메뉴 개수)가 더 많은 학교
2. 탄단지 비율이 권장 범위 중앙값에 더 근접한 학교 (탄수화물 60%, 단백질 13.5%, 지방 22.5% 기준 편차 합이 더 작은 쪽)
3. 그래도 동일하면 `SD_SCHUL_CODE` 오름차순으로 결정한다.
